# 🏭 مصنع — إمبراطورية السيارات

لعبة إدارة شركة سيارات بالأدوار (1960 → 2030). عربية، تعمل على الموبايل والكمبيوتر، بدون إنترنت، مع حفظ سحابي ولوحة متصدرين اختيارية.

## التشغيل
```
npm install
npm start        # http://localhost:3000
npm test         # اختبار المحرك (محاكاة 70 سنة)
```

## الملفات
- `index.html` — الواجهة كاملة (قوائم + رسم السيارة Canvas)
- `engine.js` — محرك اللعبة (يعمل بالمتصفح وNode)
- `server.js` — استضافة + حفظ سحابي + متصدرين
- `archive/cyberclash/` — لعبة CyberClash السابقة محفوظة كاملة
